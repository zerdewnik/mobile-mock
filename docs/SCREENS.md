# Экрандар және функциялар

Әр экран: **қалай ашылады**, **не көрсетеді**, **не істейді**. Деректер макетте жалған (`js/data.js`); нағыз нұсқада API-дан келеді.

| Хабарлама (ішкі) | 🔔 | «Отправить пуш» (тип, аудитория, атауы, мәтін), карточкалар: алды/оқыды |

| Зачисление | навбар (**тек бас куратор / академ. бөлім басшысы**; куратордан жасырын) | Оқушылар: аты-жөні және доступы бар курстары, әр курстың жанында доступ жабылуына **қалған күн** (≤30 сары, ≤7 қызыл). Іздеу өрісінің оң жағында фильтр (курс, «доступ заканчивается»). App bar-да «Зачисление ⊕» → **Зачислить**: студент (іздеумен), курс(тар) (+N), басталуы (күн немесе «Сегодня»), аяқталуы (күн немесе 1/2/3/6/9/12 ай), құны ₸, түсініктеме; бар доступ болса ұзартылады. Оқушыны басу — профиль, ұзақ басу — «Зачислить / продлить» |

| Курс прогресі | курс карточкасы | Ең жоғарыда кесте бойынша: **Сегодня / На неделе / Просрочено** (басқанда — тізім, «К модулям» қайтарады; куратор, бас куратор, академ. басшы). ## Жалпы ережелер
- **Деңгейлер:** курс сабақтарының әр 10%-ы = 1 деңгей. 128 сабақ: 13-сабақтан бастап Silver (12,8-ден асқанда).
- **Ұпай (ҰБТ):** single 1 балл; multiple/matching макс 2 (1 қате кешіріледі, 2+ қате → 0); міндетті пәндерде әр сұрақ 1 балл; максимум 140.
- **Тіл:** РУС/ҚАЗ — бүкіл интерфейс (`js/i18n.js` сөздігі).
- **Тема:** қараңғы (әдепкі) / ашық.

# Staff: Чат (кураторлар арасында)

**Орны**: Staff төменгі мәзірі — Главная · Новости · (AI) · Группы · **Чат** · Зачисление (тек бас куратор). Куратордың мәзірінде Зачисление жоқ, сондықтан 5 орын; бас куратордікі 6 орын.
Иконка: `forum` (outlined / белсенді — round).

## Тізім (Чат қойындысы)
- App bar: «Чат» + `edit_square` (жаңа хат → куратор таңдау парағы) + профиль.
- Іздеу өрісі «Куратор іздеу».
- **Кураторлар** — ортақ арна (барлық staff), жоғарыда бекітулі, күлгін топ иконкасы.
- «Кураторлар · N» — әр куратормен жеке чат: аватар 50 (бас әріптер) + онлайн нүкте, аты 15/600, соңғы хабар (өзіңдікі «Сен: …»), уақыт; оқылмаған саны (күлгін белгі) не жіберілген хабарға ✓✓.
- Бас куратор тізімде «Бас куратор» деп белгіленеді; рөлі/курсы — хабар жоқ кезде астында.

## Сөйлесу
- App bar: артқа · аватар (онлайн нүктесі) · аты + күйі («онлайн» / «жазып жатыр…» / «1 сағ бұрын болды») · қоңырау (`call`, жеке чатта).
- Хабарлар: «Бүгін» белгісі; басқалардікі сұр көпіршік (сол жақта), өзіңдікі күлгін градиент (оң жақта) + уақыт + ✓ жіберілді / ✓✓ оқылды (көк). Арнада әр жіберушінің аты өз түсімен, бас куратордың хабары «бекітілген» (сары жиек, 📌).
- «жазып жатыр» — үш секіретін нүкте.
- Төменде: 📎 тіркеу (файл, фото, отчёт) · хабар өрісі · жіберу (күлгін 3D).

## Деректер / API
`Chat {id, type: direct|channel, members[]}`, `Message {id, chatId, fromStaffId, text, attachments[], createdAt, readBy[]}`, `pinnedMessageId` (арнада бас куратор бекітеді).
`GET /staff/chats`, `GET /staff/chats/{id}/messages?before=`, `POST /staff/chats/{id}/messages`, `POST /staff/chats/{id}/read`; WS `staff_chat:{id}` — `message`, `typing`, `read`; push «Айгерим: …». Оқушылар бұл чатты көрмейді.

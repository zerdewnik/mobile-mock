# Хабарламалар (оқушы)

Нақты қосымшада: сервер оқиға болғанда **FCM push** жібереді + қосымша ішіндегі «Уведомления» тізіміне жазады. Макетте `notify({type, title, body, go})` осыны имитациялайды.

## Түрлері және қашан жіберіледі

|---|---|---|---|---|

## Батл шақыруы (кезекпен)
1. Оқушы «Досты шақыру» → пән + сыныптас → **Шақыру**.
2. Шақырылған досқа push кетеді: «{Аты} сені батлға шақырды · {пән} · 24 сағ».
3. Шақырушы өз раундын бірден ойнайды → шақыру «Жауап күтуде» бөліміне түседі.
4. Дос ойнаған соң екеуіне де нәтиже хабарламасы келеді. 24 сағатта жауап болмаса, шақырушы жеңеді.

## UI
- Тізім: иконка 32px (түрі бойынша), оқылмағаны — `primary` 10% фон + атауынан кейін қызыл нүкте 7px. App bar қоңырауында оқылмаған саны.
- App bar оң жақ: `tune` → **Хабарлама баптаулары**: әр түрге ауыстырғыш (Турниры, Батл шақырулары мен нәтижелері, Топтар шайқасы, Сабақ/эфир/конспект). Өшірілген түр push болып келмейді және тізімге түспейді.
- Staff: автоматты хабарлама «Хабарлама» тізіміне `Авто · Турнир` / `Авто · Шайқас` түрімен жазылады (кімге, неше оқушы).

## Деректер / API
`Notification {id, userId, type: tour|battle|war|study, title, body, deepLink: {tourId?|screen?|warId?}, createdAt, readAt}`
`NotifPrefs {userId, tour, battle, war, study}`
`GET /me/notifications`, `POST /me/notifications/read-all`, `PUT /me/notification-prefs`; FCM token: `POST /me/devices {fcmToken}`.

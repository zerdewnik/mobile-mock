# Апталық сынақ — куратор оқушымен өткізеді

Макет: `#staff` → Группы → оқушы → курс → модуль → «Апталық сынақ (N - апта)». Код: `openWeeklyMode()`, `runWeekly()`.

## Режим таңдау
Сынақты басқанда терезе: **Ашық сұрақ** немесе **Жабық сұрақ**. Терезеде оқушы, сұрақ саны (10) және қазіргі нәтиже.

| Режим | Экран | Куратор әрекеті |
|---|---|---|
| Ашық сұрақ | Сұрақ + «Жауабы» блогы (дұрыс жауап және түсіндірме). Жауап нұсқалары **көрсетілмейді** | Оқушы ауызша жауап береді → төменде **Дұрыс** (жасыл) / **Дұрыс емес** (қызыл); біреуін басқанда келесі сұраққа өтеді |
| Жабық сұрақ | Тренажёрдағыдай: нұсқалар → «Ответить» → Верно/Неверно + түсіндірме → «Дальше» | Оқушымен бірге таңдайды |

Жоғарғы оң жақта 🏳 **Аяқтау** (тренажёрдағыдай жалау): растаудан кейін сынақ бітеді, жауапсыз сұрақтар қате болып есептеледі.

## Балл
`балл = дұрыс / барлық сұрақ × 100` (барлық сұрақ — 10, ерте аяқталса да 10-ға бөлінеді).
Мысал: 10 сұрақ, 6 дұрыс → **60** из 100. Бұрынғы нәтиже болса (мысалы 85), ол **60-қа ауыстырылады**.

## Рейтинг
Апталық сынақ нәтижесі рейтингке түседі: оқушының апталық баллы `− бұрынғы/10 + жаңа/10` болып өзгереді, топ рейтингі қайта реттеледі.

## API (ұсыныс)
`POST /weekly-tests/{id}/sessions { studentId, mode: "open|closed" }` → 10 сұрақ · `POST /weekly-tests/sessions/{sid}/answers { qIndex, correct }` · `POST /weekly-tests/sessions/{sid}/finish` → `{ score }` (нәтиже мен рейтинг жаңарады).

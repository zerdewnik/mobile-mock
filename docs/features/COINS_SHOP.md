# I4U монеталары және Дүкен

Макет: студент → Главная (app bar-дағы 🪙 1 240) немесе Сервисы → **Магазин**.
Код: `wallet()`, `earnCoins()`, `coinChip()`, `shopHtml()`, `bindShop()`, `COIN_RULES`, `SHOP`.
Иконка: `assets/coin/coin.svg` / `coin.png` (128×128, 3D **көк** монета «I4U», I4U түстері: бет `#DDE3FF → #8A97F2 → #5B6EC2 → #3B4089`, қыры `#3B4089 → #1E2260`). Баланс тек **Магазин** ішінде көрсетіледі (жоғарғы карточка + app bar чипі `#A9B4FF`); басты беттің app bar-ында монета жоқ.

| Әрекет | Монета |
|---|---|
| Видеосабақты соңына дейін қарау | +5 |
| Конспект қабылданса | +5 |

| Апталық сынақ | +20 |
| Батлда жеңу | +15 |
| Топ соғысы: әр монета-жұлдыз (40/70/100% → 1/2/3) | +10 әрқайсысы |

Монета түскенде toast: «+10 I4U монета · Сабақ тесті».

## Дүкен
- Жоғарыда: баланс + «Қалай жинаймын?» (жоғарыдағы кесте).
- Санаттар: Аватар (жиек, атақ) · Күшейткіш (кеңес, серияны сақтау, ×2 монета) · Тақырып · Мерч (стикер, худи — офистен алу).
- Зат карточкасы: иконка, атауы, сипаттама, баға (жетпесе сұр); «Сенде бар».
- Сатып алу → растау → баланстан шегеріледі, «Монета тарихы»-на жазылады.

## Топ соғысындағы монета
Жұлдыздың орнына — I4U монеталары (0–3). Қарсылас базалары Clash секілді **дөңгелек аватар** картада; шабуыл жасалмаған база **құлыпта** (аты көрінбейді).

## API (ұсыныс)
`GET /wallet` → { coins, log[] } · `POST /wallet/earn` (сервер ішінде, әрекеттерге байланған) · `GET /shop/items` · `POST /shop/items/{id}/buy` · `GET /wallet/owned`.

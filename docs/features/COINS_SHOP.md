# I4U монеталары және Дүкен

Макет: студент → Главная (app bar-дағы 🪙 1 240) немесе Сервисы → **Магазин**.
Код: `wallet()`, `earnCoins()`, `coinChip()`, `shopHtml()`, `bindShop()`, `COIN_RULES`, `SHOP`.
Иконка: `assets/coin/coin.svg` / `coin.png` (128×128, 3D **көк** монета «I4U», I4U түстері: бет `#DDE3FF → #8A97F2 → #5B6EC2 → #3B4089`, қыры `#3B4089 → #1E2260`). Баланс тек **Магазин** ішінде көрсетіледі (жоғарғы карточка + app bar чипі `#A9B4FF`); басты беттің app bar-ында монета жоқ.

Монета түскенде toast: «+10 I4U монета · Сабақ тесті».

## Дүкен
- Жоғарыда: баланс + «Қалай жинаймын?» (жоғарыдағы кесте).
- Санаттар: Аватар (жиек, атақ) · Күшейткіш (кеңес, серияны сақтау, ×2 монета) · Тақырып · Мерч (стикер, худи — офистен алу).
- Зат карточкасы: иконка, атауы, сипаттама, баға (жетпесе сұр); «Сенде бар».
- Сатып алу → растау → баланстан шегеріледі, «Монета тарихы»-на жазылады.

## Топтар шайқасындағы монета
Жұлдыздың орнына — I4U монеталары (0–3). Қарсылас базалары Clash секілді **дөңгелек аватар** картада; шабуыл жасалмаған база **құлыпта** (аты көрінбейді).

## API (ұсыныс)
`GET /wallet` → { coins, log[] } · `POST /wallet/earn` (сервер ішінде, әрекеттерге байланған) · `GET /shop/items` · `POST /shop/items/{id}/buy` · `GET /wallet/owned`.

## Staff: Магазин (куратор / бас куратор)
Staff → Басты бет → **«Магазин»** плиткасы (`assets/v2/shopv2.png`). Үш қойынды (`.seg-tabs.seg-3`):

| Қойынды | Куратор | Бас куратор |
|---|---|---|
| **Тапсырыс** | өз топтары оқушыларының мерч тапсырыстары | барлық топтар |
| **Тауарлар** | тек көру («бас куратор басқарады») | app bar ⊕ — тауар қосу; тауарды басса — өзгерту: атауы, сипаттама, санат, баға, қалдық, «оқушылардан жасыру» |
| **Монеталар** | топ таңдау → оқушылар монета бойынша; басса — бонус: +5/10/20/50, себебі міндетті, **бір оқушыға аптасына ≤50** | +5…+500 бір реттік, лимитсіз |

Тапсырыс статусы: **Жаңа** (#F2A93B) → куратор «Дайын» басады → оқушыға «офистен алып кет» хабарламасы → **Дайын · алып кетуді күтуде** (#5B9BF2) → тапсырғанда «Берілді» → **Берілді** (#5CB36D).
Оқушы мерч сатып алса — автоматты түрде тапсырыс жасалады. Жасырын тауар оқушы дүкенінде көрінбейді.

Компонент: `.so-row` — 3D қатар (иконка 40×40 `.shop-ic`, атауы 13.5/600, мета 11.5 #8A8D9C, статус-пилюля `em` 10.5/700 түсі статуспен), оң жақта `.wr-go` немесе баға.

Деректер: `Order {id, studentId, groupId, itemId, date, status: new|ready|given}`, `CoinAward {studentId, amount, reason, byStaffId, date}`, `ShopItem {+stock, hidden}`.
API: `GET /staff/shop/orders`, `PATCH /shop/orders/{id} {status}`, `POST/PATCH /shop/items` (head), `POST /students/{id}/coins {amount, reason}` (куратор ≤50/апта).

**Тауарлар**:
- Күшейткіштер: Серияны қатыру 200 (макс 2, өздігінен), ×2 монета 350 (қолмен қосылады, 24 сағ), Кеңес ×5 150, +10 секунд ×3 120 (батл), Екінші мүмкіндік 180 (батл). ҰБТ сынағы, апталық сынақ, турнирде күшейткіш **жоқ** — әділдік үшін.

**Менің заттарым**: Күшейткіштер (саны, «Қосу» не «өздігінен»), Безендіру («Кию / Киюлі»), Тапсырыстарым (статус пилюлясы). ×2 белсенді болса — жасыл жолақ «… дейін».

**Сиректік** (Free Fire-дағыдай түс бойынша): Қарапайым `#8A93A6` · Сирек `#3D8BFF` · Эпик `#A64DFF` · Аңыз `#FF9F1A`. ## Тауар беті, баланс, тауар қосу (2026-10-06)
**Баланс** — app bar-дың оң жағында (Дүкен және тауар беттерінде): монета капсуласы (сан + жасыл «+» → монета ережелері) + «Тарих» (`history` → жиналды/жұмсалды тізімі). Дүкен бетіндегі бөлек баланс жолы алынды.

**Тауар беті** — карточканы басқанда жеке экран (парақша емес):
1. **3D сахна** 250px: зат медальоны 124px, қалыңдығы 9 қабат (CSS `preserve-3d`, `translateZ`), алдыңғы/артқы беті, 7 с-та толық айналады (`rotateX(-8°) rotateY(0→360°)`), астында тынысты көлеңке, артында сиректік түсті сәулелер. Саусақпен сырғытса бұрылады (айналу тоқтап тұрады). Flutter: `Transform(Matrix4.rotationY)` + `AnimationController(repeat)` + `GestureDetector(onHorizontalDrag)`; не дайын 3D модель (`model_viewer_plus`, .glb).
2. Сиректік капсуласы + белгі (−30% / ЖАҢА / ⏱), атауы 22/800, қысқа сипаттама. Жиек/атақ болса — «Киіп көру» (3D орнына өз аватарың) ↔ «3D көрініс».
3. Жиынтық болса — «Ішінде» + үнем.
4. **Не үшін керек** (абзац), **Қалай қолданады** (нөмірленген қадамдар), **Сипаттамалары** кестесі: Сиректік · Түрі · Әрекеті · Қайда жұмыс істейді · Шектеу · Талап (деңгей) · Қалдық · Сенде · Сатылым мерзімі.
5. Төменде бекітулі жолақ: баға (монета 24 + сан 20/900, жеңілдік болса ескі баға сызылған) + «Сатып алу» (растау терезесі) / «Кию / Шешу» / себебі (монета жетпейді, деңгей, таусылды).

**Тауарды дүкенге қалай қосады** — тек **бас куратор / академ. бөлім**: Staff → Главная → **Магазин** → «Тауарлар» → app bar **⊕** (бар тауарды өзгерту — тізімнен басу). Форма (жоғарыда карточканың тірі алдын ала көрінісі):
Атауы* · Қысқа сипаттама · Санат (Күшейткіш/Жиек/Атақ/Тақырып/Сыйлық) · Сиректік (4 түс) · Иконка (20 Material иконка) + Түс (8) · Бағасы* · Деңгей талабы · Қалдық (сыйлық үшін) · Белгі (жоқ / ЖАҢА / Шектеулі уақыт + мерзімі) · Не үшін керек · Қалай қолданады (әр қадам жаңа жолдан) · Сипаттамалары (Әрекеті / Қайда / Шектеу) · «Оқушылардан жасыру». «Дүкенге қосу» → бірден оқушылар дүкенінде көрінеді. Куратор тауар қоса алмайды (тек көреді, тапсырыстарды береді).
Деректер: `ShopItem {+why, use[], spec{act, where, limit}, tag, until, lvl, hidden}`; API `POST/PATCH /shop/items` (head), сурет керек болса `POST /shop/items/{id}/image` (.png не .glb 3D модель).

## Құттықтау анимациясы (3D) — 2026-10-07
Монета берілген **әр жағдайда** (видеосабақ соңына дейін, сабақ тесті, батлда жеңіс, топтар шайқасында шабуыл, турнир кезеңі, жетістік деңгейі, бонус) және **дүкеннен зат сатып алғанда** экран ортасына карточка шығады (тост емес):
- Фон: қараңғылау 72% + blur 3px. Карточка 310px, радиус 26, сиректік/көк түсті радиал жарқыл, айналатын сәулелер, 30 конфетти (6 түс) құлайды.
- **Монета**: 3D I4U монета 120px (алдыңғы/артқы бет + 10 қабат қыры), жоғарыдан айналып түседі (0.7 с, серпімді), кейін Y осінде айналады (1.8 с). «Құттықтаймыз!» 24/900, «+10 🪙» 40/900 — сан 0-ден 0.9 с ішінде өседі, астында себебі («Сабақ тесті тапсырылды»).

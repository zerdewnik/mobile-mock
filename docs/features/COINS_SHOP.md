# I4U монеталары және Дүкен

Макет: студент → Главная (app bar-дағы 🪙 1 240) немесе Сервисы → **Магазин**.
Код: `wallet()`, `earnCoins()`, `coinChip()`, `shopHtml()`, `bindShop()`, `COIN_RULES`, `SHOP`.
Иконка: `assets/coin/coin.svg` / `coin.png` (128×128, 3D **көк** монета «I4U», I4U түстері: бет `#DDE3FF → #8A97F2 → #5B6EC2 → #3B4089`, қыры `#3B4089 → #1E2260`). Баланс тек **Магазин** ішінде көрсетіледі (жоғарғы карточка + app bar чипі `#A9B4FF`); басты беттің app bar-ында монета жоқ.

## Монета қалай жиналады
| Әрекет | Монета |
|---|---|
| Видеосабақты соңына дейін қарау | +5 |
| Конспект қабылданса | +5 |
| Сабақ тестін тапсыру | +10 |
| Апталық сынақ | +20 |
| Батлда жеңу | +15 |
| Топтар шайқасы: әр монета-жұлдыз (40/70/100% → 1/2/3) | +10 әрқайсысы |
| Турнир: келесі кезеңге өту / чемпион | +20 / +200 |
| 7 күн қатарынан кіру | +50 |

Монета түскенде toast: «+10 I4U монета · Сабақ тесті».

## Дүкен
- Жоғарыда: баланс + «Қалай жинаймын?» (жоғарыдағы кесте).
- Санаттар: Аватар (жиек, атақ) · Күшейткіш (кеңес, серияны сақтау, ×2 монета) · Тақырып · Мерч (стикер, худи — офистен алу).
- Зат карточкасы: иконка, атауы, сипаттама, баға (жетпесе сұр); «Сенде бар».
- Сатып алу → растау → баланстан шегеріледі, «Монета тарихы»-на жазылады.

## Топтар шайқасындағы монета
Жұлдыздың орнына — I4U монеталары (0–3). Қарсылас базалары Clash секілді **дөңгелек аватар** картада; шабуыл жасалмаған база **құлыпта** (аты көрінбейді).

## API (ұсыныс)
`GET /wallet` → { coins, log[] } · `POST /wallet/earn` (сервер ішінде, әрекеттерге байланған) · `GET /shop/items` · `POST /shop/items/{id}/buy` · `GET /wallet/owned`.

## Staff: Магазин (куратор / бас куратор)
Staff → Басты бет → **«Магазин»** плиткасы (`assets/v2/shopv2.png`). Үш қойынды (`.seg-tabs.seg-3`):

| Қойынды | Куратор | Бас куратор |
|---|---|---|
| **Тапсырыс** | өз топтары оқушыларының мерч тапсырыстары | барлық топтар |
| **Тауарлар** | тек көру («бас куратор басқарады») | app bar ⊕ — тауар қосу; тауарды басса — өзгерту: атауы, сипаттама, санат, баға, қалдық, «оқушылардан жасыру» |
| **Монеталар** | топ таңдау → оқушылар монета бойынша; басса — бонус: +5/10/20/50, себебі міндетті, **бір оқушыға аптасына ≤50** | +5…+500 бір реттік, лимитсіз |

Тапсырыс статусы: **Жаңа** (#F2A93B) → куратор «Дайын» басады → оқушыға «офистен алып кет» хабарламасы → **Дайын · алып кетуді күтуде** (#5B9BF2) → тапсырғанда «Берілді» → **Берілді** (#5CB36D).
Оқушы мерч сатып алса — автоматты түрде тапсырыс жасалады. Жасырын тауар оқушы дүкенінде көрінбейді.

Компонент: `.so-row` — 3D қатар (иконка 40×40 `.shop-ic`, атауы 13.5/600, мета 11.5 #8A8D9C, статус-пилюля `em` 10.5/700 түсі статуспен), оң жақта `.wr-go` немесе баға.

Деректер: `Order {id, studentId, groupId, itemId, date, status: new|ready|given}`, `CoinAward {studentId, amount, reason, byStaffId, date}`, `ShopItem {+stock, hidden}`.
API: `GET /staff/shop/orders`, `PATCH /shop/orders/{id} {status}`, `POST/PATCH /shop/items` (head), `POST /students/{id}/coins {amount, reason}` (куратор ≤50/апта).

## Дүкен v2 — оқушы (2026-10-06)
Зерттеу: Duolingo Shop (күшейткіштер, streak freeze), Brawl Stars (күннің ұсынысы, таймер), Uchi.ru / ClassDojo (шынайы сыйлықтар, мұғалім береді).

**Бет құрылымы** (жоғарыдан төмен):
1. Баланс карточкасы: монета 56px, «Менің монеталарым» + сан 28/900; оң жақта «+ Жинау» (монета ережелері) және «Тарих» (жиналды/жұмсалды + тізім). App bar-да чип жоқ.
2. Қойындылар: **Дүкен** | **Менің заттарым · N**.
3. **Күннің ұсынысы**: күн сайын ауысатын бір зат −30%, түн ортасына дейінгі таймер, ескі баға сызылған, алтын «Сатып алу».
4. Бөлімдер (тақырып 16/700 + түсініктеме 11.5): **Күшейткіштер** · **Профиль безендіру** · **Шынайы сыйлықтар**, әрқайсысы 2 бағанды тор.

**Тауар карточкасы** `.sh-card`: 3D медальон 64×64 (радиус 20, зат түсі радиал градиент, төменгі 4px жиек), атауы 13.5/700, сипаттама 2 жол, төменде баға батырмасы 34px. Күйлері:
| Күй | Көрінісі |
|---|---|
| Сатып алуға болады | көк 3D батырма «🪙 300» |
| Монета жетпейді | сұр батырма + астында жиналған % жолағы; парақшада «тағы N» + «Қалай жинаймын?» |
| Сенде бар / Киюлі | жасыл «✓ Сенде бар» / «✓ Киюлі» |
| Деңгей жетпейді | медальон сұр, «🔒 10-деңгейден» |
| Шектеу / таусылды | «Ең көбі 2» / «Таусылды» |
| Күшейткіш саны | жоғарғы оң бұрышта «×2» |
| Шынайы сыйлық | жоғарғы сол бұрышта «қалды 12» (≤5 — қызыл) |

**Тауар парағы** (басқанда): медальон 96, атауы, сипаттама, жиек болса — өз аватарыңда алдын ала қарау, атақ болса — атыңның астында; «Қалай жұмыс істейді» тізімі; батырма «Сатып алу · 🪙500» (растаусыз — парақшаның өзі растау). Сатып алынған безендіру бірден киіледі.

**Тауарлар**:
- Күшейткіштер: Серияны қатыру 200 (макс 2, өздігінен), ×2 монета 350 (қолмен қосылады, 24 сағ), Кеңес ×5 150, +10 секунд ×3 120 (батл), Екінші мүмкіндік 180 (батл). ҰБТ сынағы, апталық сынақ, турнирде күшейткіш **жоқ** — әділдік үшін.
- Безендіру (слот: frame / title / theme, әр слотта біреуі киіледі): Алтын жиек 300, От жиегі 500, Неон жиек 450 (5-деңгей), «Тарих шебері» 400, «Батл патшасы» 600 (8-деңгей), «Неон» тақырыбы 600.
- Шынайы: стикерпак 800 (40), дәптер 1200 (25), бөтелке 2500 (12), ментормен 1:1 30 мин 3000 (10/ай), худи 5000 (5, 10-деңгей), курсқа −10% 6000 (3/ай). Сатып алғанда тапсырыс → куратор «Дайын» → push → офистен алу.

**Менің заттарым**: Күшейткіштер (саны, «Қосу» не «өздігінен»), Безендіру («Кию / Киюлі»), Тапсырыстарым (статус пилюлясы). ×2 белсенді болса — жасыл жолақ «… дейін».

Аватар жиектері: `.pf-av.fr-<id>` — конустық градиент сақина 4px + жарқыл (алтын #F2C230, от #FF6A3D, неон #4FD1FF).
Деректер: `Wallet {coins, earned, owned[], counts{id:n}, equip{frame,title,theme}, x2Until}`, `ShopItem {cat: boost|style|real, slot?, max?, lvl?, stock?, how[]}`.

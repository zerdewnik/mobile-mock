# Staff: Отчёт — куратордан есеп қалай алынады

Негіз: кураторлық **қызмет көрсету шарты**, 4 және 6-бөлім. Навбар: Главная · Новости · (AI) · Группы · **Отчёт** (`assignment`) · Зачисление (тек бас куратор).

Есеп күн сайынғы форма емес. Күндік жұмыс сол күні орындалады. **Жинақтау — сенбіде, офисте.**

## Қай ырғақ не үшін

| Ата-ана | 4.3.3 | Әр 14 күн (5 қыркүйектен). Әр оқушыға үлгерім есебі. Осы циклдің сенбісінде скрин пакетке кіреді. |

## Сенбілік пакет

Куратор санды қолмен жазбайды. Зачет — апталық сынақтан. Рейтинг — топ балынан; «топ чатына жарияладым» белгісі. Апталық есеп — қысқа мәтін. Ата-ана — жіберілгендер тізімі + WhatsApp скрині.

Тапсыру ашылады, тек пакет толық болса. Тапсырған соң өзгермейді. Бас куратор қабылдайды немесе пікірмен қайтарады. Жібермегенге еске салу.

## Бас куратор

Сол үш қойынды. Сенбіде: тапсырды / кешікті / жоқ. Пакетті ашып қабылдайды немесе қайтарады. Бүгінде — кімнің кестесі мен хаты ашық. Ата-анада — кімде скрин жетіспейді.

## Деректер

`SatPack { curatorId, date, status: draft|sent|accepted|returned, came, ratingPublished, note, game, parentSent[], shots[], officeEfirIds[], sentAt, headComment }`.

`POST /staff/reports/saturday/{date}/submit`, `POST .../accept|return {comment}`, `POST /staff/reports/remind {curatorId}`. Күндік белгілер пакетке кіреді, бөлек «жіберу» жоқ. Зачет пен рейтинг `GET /staff/reports/saturday/{date}/auto`.

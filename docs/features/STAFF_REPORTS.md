# Staff: Отчёт (куратордың күндік / апталық / айлық есебі)

Бұрынғы «Чат» қойындысының орнына. Навбар: Главная · Новости · (AI) · Группы · **Отчёт** (`assignment`) · Зачисление (тек бас куратор).

## Куратор
**Қойындылар**: Күндік · Апталық · Айлық.
**Жоғарғы карточка**: прогресс шеңбері (орындалды N/M, күлгін conic), «Күндік отчёт · 03.10.2026», мерзімі, күйі:
Толтырылуда (сары) → Жіберілді · тексерілуде (көк) → Қабылданды ✓ (жасыл) / Түзетуге қайтарылды (қызыл + бас куратордың пікірі).
**Апта жолағы** (күндікте): Дс–Сб — уақытында ✓ (жасыл), кешікті ⏱ (сары), бүгін ✎ (күлгін), алда (сұр).

**Міндеттер тізімі** (куратор күнде/аптада/айда не істеуі керек — тізім сол жерде тұрады):
| Кезең | Міндеттер (* міндетті) | Түрі |
|---|---|---|
| Күндік · 21:00 дейін | Топ чатына күн жоспары* · Сабаққа қатыспағандармен хабарласу* (хабарластым / қатыспады, жүйеден) · Сабақ тестін тапсырмағандарды тексеру* (жүйеден) · Конспект тексеру · Оқушы/ата-ана сұрақтарына жауап* · Эфир өткізу · Мәселе/ескерту | белгі / N из M / сан / мәтін |
| Апталық · Сенбі 18:00 | Апталық сынақ* (қатысты / барлығы) · Ата-аналарға отчёт WhatsApp* (жіберілді / барлығы) · Артта қалғандармен жеке жұмыс* · Апта чемпионын жариялау* · Топ белсенділігі %* (жүйеден) · Батл/турнир/ойын · Келесі аптаға жоспар* | |
| Айлық · айдың соңғы күні 18:00 | ҰБТ сынағы орташа балл* · Өсім* · Ата-аналармен жиналыс/қоңырау* · Доступы бітетіндер (ұзартты / бітетін)* · Кеткен оқушылар және себебі* · Жетістіктер мен қиындықтар* · Келесі айға мақсат* | |

Әр пункт — 3D карточка: нөмір/белгі батырмасы (орындалса жасыл ✓), атауы, өріс (сан ұяшығы 64px, «N / M», мәтін). «жүйеден» — платформа деректерінен өздігінен толады, куратор түзете алады.
**Қосымша**: түсініктеме, фото/файл тіркеу. **«Отчёт жіберу»** — барлық * толғанда белсенді (әйтпесе «Міндетті пункттерді толтырыңыз: 3/5»), растау терезесі, жіберілген соң өзгертуге болмайды. Уақытында жіберсе монета: күндік +5, апталық +20, айлық +50 (3D құттықтау).
**Тарих**: соңғы отчёттар (уақытында · 20:12 · қабылданды / кешікті · 22:05).

## Бас куратор / академ. бөлім
- Қойындылар сол; жоғарыда санақ: **жіберді** (жасыл) · **кешікті** (сары) · **жібермеді** (қызыл).
- Кураторлар тізімі: аватар, аты, курсы, күйі (Жібермеді / Кешікті · 22:10 / Жіберілді · тексеру керек / Қабылданды). Жібермегенде 🔔 **Еске салу** (push).
- Отчётты ашса — әр пункттің нәтижесі (✓ / ✕, сандар, мәтін), түсініктеме, «Бас куратордың пікірі» + **Түзетуге қайтару** (пікір міндетті) / **Қабылдау**.
- **Шаблон** — әр кезеңнің міндеттер тізімін өзгерту: өшіру, жаңа міндет қосу (түрі: белгі / сан / N из M / мәтін). Барлық кураторға бірден шығады.

## Еске салғыштар (push)
Күндік — 20:00 («1 сағат қалды»), апталық — Сенбі 16:00, айлық — соңғы күн 16:00; мерзім өтсе бас куратор тізімінде «Жібермеді».

## Деректер / API
`ReportTask {id, period: day|week|month, title, kind: check|num|of|text, required, autoSource?}`,
`Report {id, curatorId, period, key, status: draft|sent|accepted|returned, values{taskId:{done?,a?,b?}}, comment, files[], sentAt, late, headComment}`.
`GET /staff/reports?period=&key=`, `PUT /staff/reports/{id}` (draft), `POST /staff/reports/{id}/send`, `POST /staff/reports/{id}/accept|return {comment}`, `POST /staff/reports/remind {curatorId}`, `GET/PUT /staff/report-tasks` (head).

## Дизайн v2 (2026-10-09) — DingTalk / Bitrix24 жұмыс есебі + Todoist чек-лист үлгісі
- **Бас карточка** (күлгін градиент #7B52E8→#4B2F9A, 3D жиек): «Күндік отчёт» + күн 20/900, күй пилюлясы (иконкамен), прогресс жолағы 8px (сары→жасыл), «3/7 орындалды · 43%», мерзімі; күндікте апта күндері (26px шаршы: ✓ жасыл, ⏱ сары, бүгін — ақ ✎).
- Міндеттер **бөлімдерге** топталады, әр бөлім — бір карточка (тақырып жолағы: иконка 30px + атауы + «2/3», бәрі орындалса жасыл): Күндік — Топпен жұмыс · Оқушыларды бақылау · Ескерту; Апталық — Сынақ және нәтиже · Ата-ана және оқушы · Жоспар; Айлық — Нәтиже · Ата-ана және төлем · Қорытынды. Шаблонға қосылған жаңа міндеттер «Қосымша міндеттер» бөлімінде.
- Жол: дөңгелек белгі 26px (белгі түрінде — басқанда толады, мәтін сызылады; сан/мәтін түрінде — пунктир, толғанда өзі жасыл), атауы 13.5/600, міндетті болса қызыл нүкте 6px (толса жасыл).
- Сан енгізу — **степпер** (− сан +, 34px); «N / M» — степпер + жалпы сан + шағын прогресс 4px; «⚡ жүйеден» белгісі — платформадан өзі толған.
- Мәтін өрісі фокуста күлгін жарқыл. «Түсініктеме және файл» бөлімі.
- Тарих — тік уақыт сызығы (жасыл — уақытында, сары — кешікті).
- Төменде **бекітулі жолақ**: «3/4 міндетті» санағышы + «Отчёт жіберу» 50px күлгін 3D (барлық міндетті толмайынша сөнік); жіберілгенде — «Жіберілді — бас куратор тексеруде» / «Отчёт қабылданды».

# Профиль және жетістіктер (оқушы)

Зерттеу: Duolingo (профиль статистикасы + деңгейлі жетістіктер), Khan Academy (badges), Brawl Stars (профиль безендіру).

## Профиль беті (жоғарыдан төмен) — 2026-10-06 жеңілдетілді
1. **Карточка**: аватар 88px + киілген жиек (дүкеннен), аты 22/700, киілген атақ пилюлясы (болса). Оң жақ жоғарыда ✎. Топ/пән/деңгей жолы, статистика (серия, монета, рейтинг, белбеу) және медальдар қатары **жоқ**.
2. Мәзір блогы (`menu-block`): **Менің жетістіктерім** (`military_tech` → барлық жетістіктер парағы) · **Менің заттарым** (`inventory_2` → Дүкен/заттарым) · **Монета тарихы** (`history`).
3. Бұрынғы баптаулар (компания, шарттар, тема, тіл, Instagram, WhatsApp, Админ-панель).

## Медаль `.ach-med`
Дөңгелек 58px (тізім) / 52 (профиль) / 96 (парақ), 3D: радиал градиент + жоғарғы ақ жарқыл + төменгі 4px жиек + көлеңке, ортасында ақ Material иконка; астында ★ саны (деңгей).
Түстер: қола `#F6C9A0 → #CD7F32 → #8A4E1A`, күміс `#FFFFFF → #B8C2CC → #6E7A86`, алтын `#FFF1B8 → #F2C230 → #B57A0A`, ашылмаған `#4A4A52 → #34343C → #24242A` (иконка #6C6F84).
**Барлығы** парағы: «9/12 ашылды» + қола/күміс/алтын саны, 3 бағанды тор (медаль, атауы, прогресс жолағы 4px, «64/200» не MAX).
**Бір жетістік** парағы: медаль 96, деңгейі, үш қадам тізімі (орындалғаны ✓, ағымдағысы көк жиекпен, әрқайсысының монета сыйлығы), келесі деңгейге прогресс.

API: `GET /me/profile` (stats, equip), `GET /me/achievements` → `[{id, tier, cur, steps[]}]`; деңгей ашылғанда сервер `achievement_unlocked` push + монета.

## Профильді өзгерту (✎, 2026-10-06)
Профиль карточкасындағы ✎ → парақша «Профильді өзгерту»:
- **Фото**: аватар 88px + камера белгісі (басса таңдау) · «Фото қою / Фотоны ауыстыру» · «Өшіру». Сурет ортасынан шаршы етіп қиылып, 256×256 JPEG (0.85) болып сақталады; фото жоқ болса — бас әріптер. Flutter: `image_picker` (галерея + камера) + `image_cropper` (шеңбер қию), серверге `POST /me/avatar` (multipart).
- **Аты*** · **Тегі*** (екі баған, макс 30 таңба) · Туған күні (date) · Қала · Мектеп · Сынып (9 / 10 / 11 / Түлек).
- **Телефон** — тек оқу (құлып): нөмір логин болғандықтан, өзгерту қолдау қызметі арқылы.
- «Сақтау» → профиль, рейтинг, батл, турнир, шайқаста жаңа аты мен фотосы бірден көрінеді (аватар барлық жерде `photo` болса суретпен).
API: `PATCH /me {firstName, lastName, birthDate, city, school, grade}`, `POST /me/avatar`, `DELETE /me/avatar`.

## Өткен апта чемпионы — өз фотосы (2026-10-06)
Топ бетіндегі «Чемпион прошлой недели» карточкасының оң жағында — **чемпионның өз профиль фотосы** (оқушы профильді өзгертуде қояды), дөңгелек 112px, алтын сақина (`#D4A72C`, 3px + 4px қараңғы аралық) + жарқыл, үстінде алтын кубок белгісі 34px. Фото жоқ болса — оның аватары (бас әріптер, өз түсі). Бұрынғы «фото қою» камерасы (кез келген суретті қолмен қою) алынды — сурет тек оқушының өз профилінен алынады.

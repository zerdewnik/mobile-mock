# Ойындар (студент және куратор)

Плитка: Главная → Сервисы → **Ойындар** (Турниры жанында), иконка `assets/tournament/games_line.png` (геймпад, stroke 32, `#2EC4B6`). Екі режимде де бар.
Хаб: үш 3D карточка (медальон 64 + режим белгісі + атауы + сипаттама + статистика). Монета: Бұқа мен сиыр +10, Дар ағашы +5, Мафияда команда жеңсе +20 — **әр ойыннан күніне ең көбі 3 рет** (ойын оқудан маңызды болмасын). Әр ойынның ⓘ ережесі бар.

## 1. Бұқа мен сиыр — ботпен
- Екеуі де 4 **әр түрлі** цифрдан құпия сан ойлайды (0 бірінші болуы мүмкін, 5040 нұсқа). Сен өз санынды енгізесің (не «Кездейсоқ»), бот өзінікін.
- Кезекпен болжайсыңдар: 🟢 **бұқа** — цифр да, орны да дұрыс; 🟡 **сиыр** — цифр бар, орны басқа. Мысал: құпия 1234, болжам 1325 → 1 бұқа, 2 сиыр.
- Бірінші 4 бұқа тапқан жеңеді (сен бірінші жүресің; сен тапсаң бот жүрмейді).
- Бот: **Қиын** — әр жолы барлық бұрынғы жауаптарға сай келетін нұсқалардың бірін таңдайды (орташа 5–6 жүрісте табады); **Жеңіл** — 45% жағдайда кездейсоқ болжайды.
- Экран: «Сенің кезегің / Бот ойлануда…» · екі баған (Сен → бот, Бот → сен; әр жолда сан + «N бұқа N сиыр» + 4 нүкте) · «Менің саным ••••» (көрсету/жасыру) · 4 ұяшық + цифр пернетақтасы (қолданылған цифр сөнеді) · соңында нәтиже + боттың саны + «Қайта ойнау».

## 2. Мафия — топпен, тіркелу, жүргізуші
**Кеш ашу** (куратор не оқушы — ашқан адам **жүргізуші**, ол ойнамайды): атауы, басталуы, кімдер тіркеле алады (куратор — өз топтары, оқушы — өз тобы), ең көп қатысушы 6/8/10/12, талқылау 1/2/3 мин. Ашылғанда топқа push «Мафия кеші: тіркелу ашық».
**Лобби**: Қазір / Тіркелу / Өткен кештер; карточкада статус, «Тіркелдің», «Сен жүргізесің», уақыт, жүргізуші, аватарлар, N/max, нәтиже.
**Бөлме**: рөлдер кестесі (адам санына қарай), тіркелгендер; батырма: «Тіркелу / Тіркелуден шығу» · басталса «Ойынға кіру» · жүргізушіге «Ойынды бастау» (кемінде 6).
**Рөлдер**: мафия — 6–7 адамда 1, 8–9-да 2, 10+ — 3; дәрігер 1; комиссар 1; қалғаны тұрғын. Жасырын таратылады; мафиялар бір-бірін көреді.
**Цикл**: 🎭 рөлдер (карточка 3D аударылады, «ешкімге көрсетпе») → 🌙 түн (мафия біреуді таңдайды, дәрігер біреуді емдейді — өзін де, комиссар біреуді тексереді; тұрғындар «қала ұйықтап жатыр») → 🌅 таң (жүргізуші нәтижені жариялайды: кім шықты + рөлі, не «дәрігер құтқарды»; комиссарға жеке нәтиже) → 💬 талқылау (таймер) → 🗳 дауыс беру (әр тірі ойыншы 1 дауыс; ең көп дауыс — шығады, рөлі ашылады; тең болса ешкім шықпайды) → ⚖️ үкім → келесі түн.
**Жеңіс**: мафия жойылса — тұрғындар; мафия саны қалғандарға тең не көп болса — мафия. Шыққан ойыншы бақылаушы болады (рөлдер ашық көрінеді, сөйлеуге болмайды).
**Жүргізуші экраны**: барлық рөлдер көрінеді, әр фазаға нұсқау + келесі фазаға батырма (Түн басталсын → Таң атты → Талқылау → Дауыс беру → Дауысты санау → Келесі түн). Түн фонында көк градиент.
API/WS: `POST /mafia/rooms`, `POST /mafia/rooms/{id}/join|leave|start`, WS `room:{id}`: `phase`, `night_action {target}`, `vote {target}`, `reveal`; рөлдерді **сервер** таратады және тек иесіне жібереді.

## 3. Дар ағашы — адамдармен
- **Жіберу**: оқушы — досына (сыныптасы), куратор — **бүкіл топқа** (алғашқы 3 шешкенге +5). Сөз 3–14 қазақ әрпі (тек әріп, автомат үлкен әріп), санат (Тарих, Биология, География, Ағылшын, Жалпы), кеңес. Алушыға push.
- **Ойнау**: кімнен, санат, әріп саны, қалған мүмкіндік; SVG дар ағашы — 7 қате (бас, дене, 2 қол, 2 аяқ, көз); сөз ұяшықтары; кеңес; қазақ әліпбиі пернетақтасы 42 әріп (7×6; дұрыс — жасыл, қате — қызыл, сөнеді).
- Тапса — +5, жіберушіге «тапты · N қате» хабарламасы; таппаса — сөз ашылады.
- Хаб: «Сені күтіп тұрған сөздер» · «Мен жіберген сөздер» (статусы).

Хабарлама түрі `game` (баптауларда «Ойындар»): мафия кеші ашылды / басталды, сөз келді, нәтиже.

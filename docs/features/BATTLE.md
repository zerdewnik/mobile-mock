# Батл (1v1 жекпе-жек)

Макет: студент → Главная → Сервисы → **Батл**. Үлгі: Trivia Crack / QuizDuel (кезекпен, асинхронды) және chess.com рейтингі.

## Экран
- App bar: ⓘ — ережелер терезесі (бетте ереже блогы жоқ).
- Қойындылар: **Ойнау** / **Тарих** (жеңіс жасыл, жеңіліс қызыл жиек, есеп, ↻ реванш).
- **Топтар шайқасы** карточкасы — **features/GROUP_WAR.md**.
- **Өз тобымнан қарсылас** (деңгейі жақын сыныптас). **Досты шақыру** — app bar-дағы 👤+ белгісі. Басқа топпен жарыс тек «Топтар шайқасы» арқылы (ортақ пән бойынша).
- **Статистика:** Батл рейтингі (бастапқы 1000), жеңіс/жеңіліс, жеңіс сериясы 🔥.
- **Кездейсоқ қарсылас:** өз тобынан деңгейі жақын оқушы (рейтинг бойынша) — бірден ойын.
- **Досты шақыру:** пән + сыныптас → шақыру кетеді.
- **Саған шақыру:** келген шақырулар (кімнен, пән, қалған уақыт) — «Қабылдау» / ✕.
- **Жауап күтуде:** сен ойнап қойған, қарсылас әлі ойнамаған батлдар (сенің ұпайың, қалған уақыт).
- **Менің батлдарым:** тарих (есеп, күні) + ↻ реванш.

## Ережелер
- 3 раунд: Жеңіл 5×1, Орта 5×2, HARD 3×3 = макс 24 ұпай; әр сұраққа 20 с.
- **Асинхронды:** шақыру алған оқушыға 24 сағат; уақыт өтсе — шақырушы жеңеді.
- Тең ұпай → жылдамырақ жауап берген жеңеді.
- Рейтинг: жеңіс +15, жеңіліс −10 (нағыз нұсқада Elo: қарсыластың рейтингіне қарай).

## API (ұсыныс)
`POST /battles { opponentId | random:true, subject }` · `GET /battles?status=incoming|waiting|finished` · `POST /battles/{id}/accept` · `POST /battles/{id}/decline` · `POST /battles/{id}/answers` · `GET /battles/rating`.

## Екі режим: онлайн және кезекпен (2026-10-06)
Шақыру терезесі (app bar `person_add`): пән → сыныптас (онлайндар жоғарыда, аватарда жасыл нүкте 11px `#4CC96B`, астында «онлайн» не «1 сағ бұрын») → екі батырма:
| Батырма | Қашан белсенді | Не болады |
|---|---|---|
| **Кезекпен** (`schedule`, ghost) | кез келген сыныптас | Досқа push «X сені батлға шақырды · 24 сағ». Шақырушы өз раундын бірден ойнайды → «Жауап күтуде». Дос ойнаған соң екеуіне нәтиже. 24 сағатта ойнамаса — шақырушы жеңеді |
| **Қазір ойнау** (`bolt`, primary) | тек дос онлайн болса | Досқа 60 с шақыру (толық экранды push/дыбыс). Күту парағы: аватар, 60→0 санағыш шеңбер (96px, пульс), «Болдырмау» / «Кезекпен ойнау». Қабылдаса — екеуі бір уақытта ойнайды. 60 с ішінде жауап болмаса — шақыру **өздігінен кезекпен** ойнауға ауысады |

Онлайн жекпе-жек экраны: ортада «● ОНЛАЙН» белгісі (жасыл), сұрақ астында қарсылас күйі: «{аты} ойланып жатыр…» → жауап бергенде «✓ {аты} жауап берді» (дұрыс/қате көрсетілмейді, тек өзің жауап бергенде ашылады). Раундтар арасындағы заставка батырмасыз, 2.5 с кейін екеуіне бірге басталады. Ұпай тең болса — жылдамырақ жауап берген жеңеді.

Техникалық: presence (соңғы 60 с белсенділік) + WebSocket бөлмесі `duel:{id}`; сервер сұрақтарды және әр сұрақтың басталу уақытын екеуіне бірдей жібереді; байланыс 15 с үзілсе — қалған сұрақтар үзілген ойыншыға 0 ұпай.
API: `POST /duels {opponentId, subjectId, mode: live|async}`, `POST /duels/{id}/accept`, WS `answer {q, option, ms}` / `opponent_answered {q}` / `reveal {q, correct, scores}`.

- Шақыру парағы тұрақты биіктікте: сыныптастар тізімі ортада айналады, «Кезекпен» / «Қазір ойнау» батырмалары әрдайым ең төменде. Сыныптасты бір басса — таңдалады, қайта басса — алынады (екі батырма қайта сөнеді).

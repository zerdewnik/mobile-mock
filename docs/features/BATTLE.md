# Батл (1v1 жекпе-жек)

Макет: студент → Главная → Сервисы → **Батл**. Үлгі: Trivia Crack / QuizDuel (кезекпен, асинхронды) және chess.com рейтингі.

## Экран
- App bar: ⓘ — ережелер терезесі (бетте ереже блогы жоқ).
- Қойындылар: **Ойнау** / **Тарих** (жеңіс жасыл, жеңіліс қызыл жиек, есеп, ↻ реванш).
- **Топтар шайқасы** карточкасы — **features/GROUP_WAR.md**.
- **Өз тобымнан қарсылас** (деңгейі жақын сыныптас). **Досты шақыру** — app bar-дағы 👤+ белгісі. Басқа топпен жарыс тек «Топтар шайқасы» арқылы (ортақ пән бойынша).
- **Статистика:** Батл рейтингі (бастапқы 1000), жеңіс/жеңіліс, жеңіс сериясы 🔥.
- **Кездейсоқ қарсылас:** өз тобынан деңгейі жақын оқушы (рейтинг бойынша) — бірден ойын.
- **Досты шақыру:** пән + сыныптас → шақыру кетеді.
- **Саған шақыру:** келген шақырулар (кімнен, пән, қалған уақыт) — «Қабылдау» / ✕.
- **Жауап күтуде:** сен ойнап қойған, қарсылас әлі ойнамаған батлдар (сенің ұпайың, қалған уақыт).
- **Менің батлдарым:** тарих (есеп, күні) + ↻ реванш.

## Ережелер
- 3 раунд: Жеңіл 5×1, Орта 5×2, HARD 3×3 = макс 24 ұпай; әр сұраққа 20 с.
- **Асинхронды:** шақыру алған оқушыға 24 сағат; уақыт өтсе — шақырушы жеңеді.
- Тең ұпай → жылдамырақ жауап берген жеңеді.
- Рейтинг: жеңіс +15, жеңіліс −10 (нағыз нұсқада Elo: қарсыластың рейтингіне қарай).

## API (ұсыныс)
`POST /battles { opponentId | random:true, subject }` · `GET /battles?status=incoming|waiting|finished` · `POST /battles/{id}/accept` · `POST /battles/{id}/decline` · `POST /battles/{id}/answers` · `GET /battles/rating`.

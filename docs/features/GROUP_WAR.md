# Топ соғысы (Clash of Clans «Clan War» үлгісімен)

Макет: студент → Батл → «Топ соғысы» карточкасы → соғыс картасы; куратор (`#staff`) → Главная → Сервисы → **Топ соғысы**.
Код: `war()`, `warCardHtml()`, `openWar()`, `openWarStart()`, `warRules()`, `simAttacks()`, `warTotals()`.

## Кім бастайды
Тек топтың **кураторы** (немесе бас куратор / академ. басшы — кез келген топ үшін). Оқушы соғыс аша алмайды.

## Бастау (куратор)
| Өріс | Ереже |
|---|---|
| Топ | куратордың тобы |
| Соғыс көлемі | 5×5 · 10×10 · 15×15 (топта жеткілікті оқушы болуы керек) |
| Қатысушылар | дәл N оқушы; «рейтинг бойынша үздіктер» — автоматты таңдау |
| Дайындық күні | 12 / 24 / 48 сағат |
| Қарсылас іздеу | **тек ортақ пәні бар** (топтың курсы бірдей, яғни оқушылардың «Мои курсы»-нда бар) және көлемі жететін топтар; күші (орташа рейтинг) ең жақын топ таңдалады |

«Соғысты бастау» → екі топқа пуш, мәртебе `prep`.

## Кезеңдер
1. **Дайындық күні** — шабуыл жоқ; оқушылар соғыс пәнін тренажёрда қайталайды.
2. **Шайқас күні** (24 сағ) — әр қатысушыға **2 шабуыл**; қарсыластың кез келген базасына, бірақ бір базаға бір рет.
3. **Аяқталды** — нәтиже, «Өткен соғыстар» тарихы.

## Шабуыл
Шабуыл = 1v1 жекпе-жек (3 раунд, 13 сұрақ, макс 24 ұпай), пән — соғыс пәні.
`% = ұпай / 24 × 100` → **40% = 1, 70% = 2, 100% = 3 I4U монета** (жұлдыздың орнына монета; оқушының әмиянына да түседі, әрқайсысы +10).
Әр қарсылас базасы үшін топтың **ең жақсы** нәтижесі есептеледі.

## Жеңіс
Көп ★ жинаған топ; тең болса — орташа % (бұзу пайызы) жоғары топ.

## Экрандар
- **Батл беті:** «Топ соғысы» карточкасы — мәртебе (Дайындық/Шайқас/Жеңіс), қалған уақыт, ★ есебі, %, «Сенің шабуылдарың ⚔️⚔️ · 2 қалды».
- **Соғысты ашқан** адам hero-да анық көрсетіледі («Соғысты ашқан: Диана · куратор»).
- **Соғыс картасы:** қарсылас базалары Clash секілді дөңгелек аватарлар (зигзаг карта); шабуыл жасалмағаны — құлыпта; жоғарыда есеп пен жолақ; қойындылар **Қарсылас** (позиция, аты, рейтинг, алынған ★, «шабуылдау» батырмасы) / **Біздің топ** (әр мүшенің 2 шабуылы және қорғаныста берген ★) / **Шабуылдар** (журнал); ⓘ — ережелер.
- **Куратор:** соғыс картасы + «Соғысты аяқтау» / «Жаңа соғыс бастау».

## API (ұсыныс)
`POST /wars { groupId, size, memberIds, prepHours }` → іздеу · `GET /wars/current?groupId=` · `POST /wars/{id}/attacks { targetId }` → жекпе-жек · `POST /wars/{id}/finish` · `GET /wars?groupId=&status=ended`.
Сервер: сәйкестендіру (ортақ курс + көлем + орташа рейтинг), кезең ауысуы (cron), пуш.

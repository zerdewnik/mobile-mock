# Турнир және жекпе-жек — техникалық сипаттама

Макет: студент → Главная → Сервисы → **Турнир** (батл — бөлек «Батл» сервисі); куратор (`#staff`) → Главная → Сервисы → Турнирлер.
Код: `js/app.js` → `tournaments()`, `openTournament()`, `openStaffTournaments()`, `openTourForm()`, `startDuel()`, `openDuelInvite()`.

## 1. Рөлдер

| Рөл | Не істей алады |
|---|---|
| **Куратор** | Өз топтарына турнир ашады; модуль мен тақырыптарды таңдайды; мерзімдерді қояды; тіркелуді жауып, турнирді бастайды; кестені бақылайды |
| **Бас куратор** | Бірнеше топқа ортақ турнир ашады (топтар тізімінде бірнешеуін таңдау) |
| **Оқушы** | Өз тобына ашылған турнирге тіркеледі / бас тартады; өз жекпе-жегін ойнайды; кестені көреді; сыныптасын достық жекпе-жекке шақырады |

## 2. Турнир құру (куратор)

«Турнирлер» тақырыбының оң жағындағы **«+»** → форма (барлығы міндетті):

| Өріс | Түрі | Ереже |
|---|---|---|
| Атауы | мәтін | 1–60 таңба |
| Қатысатын топтар | көп таңдау (чиптер) | куратор — өз топтары; бас куратор — барлық топ |
| Пән | бір таңдау | платформадағы кез келген пән |
| Модульдер | жабық өріс → басқанда **чекбокс** тізімі ашылады, «барлығын таңдау»; өрісте таңдалғандар мен саны | таңдалған пәннің модульдері, бірнешеуі |
| Тақырыптар | модульдер сияқты жабық өріс → басқанда ашылады (модуль таңдалмаса — белсенді емес) | таңдалған модульдердің тақырыптары (әр тақырыптың астында модулі); сұрақтар тек осылардан |
| Тіркелу аяқталады · Турнир басталады | күн+уақыт, **бір жолда** | басталуы тіркелуден кейін |
| Бастапқы кезең | 1/16 · 1/8 · 1/4 · Жартылай финал | қатысушылар саны 32 / 16 / 8 / 4 |
| Кезеңдердің басталу уақыты | әр кезеңге күн+уақыт | бірінші кезең = «Турнир басталады»; қалғаны әдепкі +1 күннен, өзгертуге болады; әр кезең алдыңғысынан кейін |

«Турнирді жариялау» → мәртебе `registration`, топ оқушыларына пуш: «Жаңа турнир: {атауы}. Тіркелу {күні} дейін».

## 2а. Өшіру, тоқтату, архив (куратор)
| Мәртебе | Әрекет | Нәтиже |
|---|---|---|
| `registration` | «Турнирді өшіру» (растау) | Турнир жойылады, тіркелгендерге пуш |
| `running` | «Турнирді тоқтату» (растау) | `cancelled`, ойналмаған матчтар жабылады, архивке түседі |
| `finished` / `cancelled` | «Архивтен өшіру» (растау) | Нәтижелерімен біржола жойылады |

**Өткен турнирлер:** куратордың тізімінде «Өткен турнирлер · архив» (аяқталған + тоқтатылған), студентте «Өткен турнирлер» (тек аяқталған: чемпион, күні, толық кесте).

## 3. Тіркелу (оқушы)
- Турнир карточкасы «Тіркелу ашық» бөлімінде; ішінде: ұйымдастырушы, топтар, модуль, тақырыптар, тіркелгендер саны, кесте, ереже.
- «Тіркелу» → `participants`-ке қосылады; «Тіркелуден бас тарту» — тіркелу жабылғанша.
- Тіркелу мерзімі өткенде (немесе куратор «Тіркелуді жабу және бастау» басқанда) → `running`. Кемінде 2 қатысушы керек.

## 4. Кесте (олимпиялық жүйе)
- Қатысушылар кездейсоқ орналастырылады; өлшем = 2-нің келесі дәрежесі (9 адам → 16).
- Жетпеген орындар — **BYE**: ол оқушы 1-кезеңде қарсыласысыз өтеді.
- Кезеңдер: … → 1/8 → 1/4 → Жартылай финал → Финал → Чемпион.
- Әр кезеңнің мерзімі: `start + k × stageDays`. Мерзім ішінде:
  - екеуі ойнаса — көп ұпай жинаған өтеді;
  - біреуі ғана ойнаса — ойнаған өтеді;
  - ешқайсысы ойнамаса — топ рейтингінде жоғары тұрған өтеді.
- Кезеңнің барлық жұбы аяқталғанда сервер келесі кезеңнің жұптарын құрады және оқушыларға пуш жібереді: «Сенің жекпе-жегің: {қарсылас}, {күні} дейін».

## 5. Жекпе-жек (бір матч)

| Раунд | Сұрақ | Ұпай | Деңгей |
|---|---|---|---|
| 1 · Жеңіл | 5 | ×1 | A (оңай) |
| 2 · Орта | 5 | ×2 | B |
| 3 · HARD | 3 | ×3 | C (күрделі) |
| **Барлығы** | **13** | **макс 24** | |

- Әр сұраққа **20 секунд**; уақыт бітсе — қате.
- Екі ойыншы **бірдей сұрақтарды** алады (сервер матч басында генерациялайды).
- Асинхронды: әр оқушы кезең мерзімі ішінде өз уақытында ойнайды; нәтиже екеуі де бітіргенде ашылады. (Синхронды режим — кейін.)
- Тең ұпай → жалпы жауап уақыты аз адам жеңеді; ол да тең болса — рейтингте жоғары тұрған.
- Сұрақ көзі: ҰБТ банкі (`ent-bank`), турнирдің тақырыптары бойынша, `difficulty` A/B/C бойынша.

## 6. Достық жекпе-жек (шақыру)
- Оқушы → «Жарысқа шақыру» → пән (тренажёр пәндері) + сыныптас → шақыру (пуш).
- Қарсылас 24 сағат ішінде қабылдайды → екеуі де ойнайды → нәтиже, «Реванш».
- Турнир кестесіне әсер етпейді; тарихта сақталады.

**Endpoint-тер:**
`POST /tournaments` (куратор) · `GET /tournaments?groupId=` · `GET /tournaments/{id}` · `POST /tournaments/{id}/register` · `DELETE /tournaments/{id}/register` · `POST /tournaments/{id}/start` · `POST /tournaments/{id}/cancel` · `DELETE /tournaments/{id}` · `GET /matches/{id}` · `POST /matches/{id}/answers` · `POST /duels` (шақыру) · `POST /duels/{id}/accept`.

**Фон тапсырмалары (cron):** тіркелу мерзімі өткенде бастау; кезең мерзімі өткенде ойналмаған матчтарды жабу және келесі кезеңді құру; пуш хабарламалар.

## 8. Экрандар (макеттегі)

| Экран | Компоненттер |
|---|---|
| Турнир тізімі | `.t3-sec` бөлімдер (Тіркелу ашық / Өтіп жатыр / Аяқталған), `.t3-card` (иконка 58: register/duel/trophy.svg, бейдж, атауы, пән·модуль, күй жолы), шақыру панелі |
| Турнир беті | `.t3-hero` (trophy.svg 96), әрекет (Тіркелу / Сен тіркелдің / VS + «Жекпе-жекті бастау» / шықтың / чемпион), ақпарат панелі, кезеңдер уақыт сызығы `.t3-tl`, тіркелгендер торы / турнир кестесі `.br`, ереже |
| Жекпе-жек | ұпай жолағы, 13 нүкте (раунд түсімен), таймер 20 с, сұрақ, жауаптар (дұрыс жасыл / қате қызыл), қарсылас нәтижесі, раунд кіріспесі, нәтиже беті |
| Куратор · Турнирлер | «Турнир құру» (3D батырма), тізім |
| Куратор · Форма | `openTourForm()` |

Түстер: батырмалар (Тіркелу, Бастау, Жекпе-жекті бастау) — primary: студентте көк, staff-та күлгін. Алтын тек белбеу мен чемпион карточкасында, раундтар: жасыл / сары / қызыл.

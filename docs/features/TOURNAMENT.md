# Турнир және жекпе-жек — техникалық сипаттама

Макет: студент → Главная → Сервисы → **Турнир** (батл — бөлек «Батл» сервисі); куратор (`#staff`) → Главная → Сервисы → Турнирлер.
Код: `js/app.js` → `tournaments()`, `openTournament()`, `openStaffTournaments()`, `openTourForm()`, `startDuel()`, `openDuelInvite()`.

## 1. Рөлдер

| Рөл | Не істей алады |
|---|---|
| **Куратор** | Өз топтарына турнир ашады; модуль мен тақырыптарды таңдайды; мерзімдерді қояды; тіркелуді жауып, турнирді бастайды; кестені бақылайды |
| **Бас куратор** | Бірнеше топқа ортақ турнир ашады (топтар тізімінде бірнешеуін таңдау) |
| **Оқушы** | Өз тобына ашылған турнирге тіркеледі / бас тартады; өз жекпе-жегін ойнайды; кестені көреді; сыныптасын достық жекпе-жекке шақырады |

## 2. Турнир құру (куратор) — 4 қадам

Үлгі: Challonge (формат таңдау, жұптастыру, check-in) және chess.com (Arena / Swiss / Knockout, кері санақ).
«Турнирлер» тақырыбындағы **«+»** → қадамдық форма (жоғарыда 1–4 қадам индикаторы, «Артқа / Әрі қарай»):

| Қадам | Өрістер |
|---|---|
| 1 · Формат | Атауы; **баннерлер (3-ке дейін)** — турнир бетінің басында карусель және тіркелу/өтіп жатқанда басты беттегі баннерде; формат: **Олимпиялық** (жеңілген шығады; кезең саны −/+ → қатысушылар 4–32), **Швейцар жүйесі** (ешкім шықпайды, раунд саны 3–9, ұпайы тең оқушылар кездеседі, жеңіс = 1), **Арена** (1 / 3 сағат / 1 күн; қанша ойнасаң сонша ұпай: жеңіс 2, 3 жеңістен бастап 🔥 4) |
| 2 · Қатысушылар | **Бас куратор / академ. басшы:** «Барлық оқушылар» (платформаның бәріне) немесе «Таңдалған топтар»; топтар (куратор — өз, бас куратор — бәрі) + оқушы саны орынмен салыстыру; жұптастыру: **рейтинг бойынша** (1-орын соңғымен) / кездейсоқ; **Check-in** (басталардан 30 мин бұрын растау) |
| 3 · Мазмұн | Пән (кез келген); модульдер мен тақырыптар — басқанда ашылатын чекбокс тізімі |
| 4 · Уақыт | Тіркелу аяқталады · Турнир басталады (бір жолда); олимпиялықта **әр кезеңнің күні мен уақытын куратор өзі қояды** (бірінші = «Турнир басталады», әдепкі +1 сағаттан; бірнеше кезеңді бір күнге қоюға болады; әр кезең алдыңғысынан кейін болуы тексеріледі); швейцарда раунд аралығы 1/2/3 күн/1 апта; **алдын ала көрініс** |

Оқушыда: тіркелу кезінде **кері санақ** («Басталуына 3 күн 19 сағ»), check-in ескертуі. Швейцар/Аренада тор орнына **ұпай кестесі** (орын, Ж/Ж, ұпай, 🔥 серия) және «Раундты ойнау» / «Келесі ойын».

«Турнирді жариялау» → мәртебе `registration`, топ оқушыларына пуш: «Жаңа турнир: {атауы}. Тіркелу {күні} дейін».

## 2а. Өшіру, тоқтату, архив (куратор)
| Мәртебе | Әрекет | Нәтиже |
|---|---|---|
| `registration` | «Турнирді өшіру» (растау) | Турнир жойылады, тіркелгендерге пуш |
| `running` | «Турнирді тоқтату» (растау) | `cancelled`, ойналмаған матчтар жабылады, архивке түседі |
| `finished` / `cancelled` | «Архивтен өшіру» (растау) | Нәтижелерімен біржола жойылады |

**Өткен турнирлер:** куратордың тізімінде «Өткен турнирлер · архив» (аяқталған + тоқтатылған), студентте «Өткен турнирлер» (тек аяқталған: чемпион, күні, толық кесте).

## 3. Тіркелу (оқушы)
- Турнир карточкасы «Тіркелу ашық» бөлімінде; ішінде: ұйымдастырушы, топтар, модуль, тақырыптар, тіркелгендер саны, кесте, ереже.
- «Тіркелу» → `participants`-ке қосылады; «Тіркелуден бас тарту» — тіркелу жабылғанша.
- Тіркелу мерзімі өткенде (немесе куратор «Тіркелуді жабу және бастау» басқанда) → `running`. Кемінде 2 қатысушы керек.

## 4. Кесте (олимпиялық жүйе)
- Қатысушылар кездейсоқ орналастырылады; өлшем = 2-нің келесі дәрежесі (9 адам → 16).
- Жетпеген орындар — **BYE**: ол оқушы 1-кезеңде қарсыласысыз өтеді.
- Кезеңдер: … → 1/8 → 1/4 → Жартылай финал → Финал → Чемпион.
- Әр кезеңнің мерзімі: `start + k × stageDays`. Мерзім ішінде:
  - екеуі ойнаса — көп ұпай жинаған өтеді;
  - біреуі ғана ойнаса — ойнаған өтеді;
  - ешқайсысы ойнамаса — топ рейтингінде жоғары тұрған өтеді.
- Кезеңнің барлық жұбы аяқталғанда сервер келесі кезеңнің жұптарын құрады және оқушыларға пуш жібереді: «Сенің жекпе-жегің: {қарсылас}, {күні} дейін».

## 5. Жекпе-жек (бір матч)

| Раунд | Сұрақ | Ұпай | Деңгей |
|---|---|---|---|
| 1 · Жеңіл | 5 | ×1 | A (оңай) |
| 2 · Орта | 5 | ×2 | B |
| 3 · HARD | 3 | ×3 | C (күрделі) |
| **Барлығы** | **13** | **макс 24** | |

- Әр сұраққа **20 секунд**; уақыт бітсе — қате.
- Екі ойыншы **бірдей сұрақтарды** алады (сервер матч басында генерациялайды).
- Асинхронды: әр оқушы кезең мерзімі ішінде өз уақытында ойнайды; нәтиже екеуі де бітіргенде ашылады. (Синхронды режим — кейін.)
- Тең ұпай → жалпы жауап уақыты аз адам жеңеді; ол да тең болса — рейтингте жоғары тұрған.
- Сұрақ көзі: ҰБТ банкі (`ent-bank`), турнирдің тақырыптары бойынша, `difficulty` A/B/C бойынша.

## 6. Достық жекпе-жек (шақыру)
- Оқушы → «Жарысқа шақыру» → пән (тренажёр пәндері) + сыныптас → шақыру (пуш).
- Қарсылас 24 сағат ішінде қабылдайды → екеуі де ойнайды → нәтиже, «Реванш».
- Турнир кестесіне әсер етпейді; тарихта сақталады.

## 9. Баннер және чемпион
- Басты бет каруселі: негізгі I4U баннері → аяқталған турнирлердің **чемпион баннері** (аты, турнир, белбеу) → тіркелу ашық/өтіп жатқан турнирлердің баннерлері → жаңалық-баннерлер. 4 секунд сайын автоматты ауысады; басқанда — турнир беті.
- Турнир беті: баннер болса — карусель (атауы үстінде), болмаса — жинақы тақырып (белбеу иконкасы + атауы).
- Ережелер бетте тұрмайды: app bar-дағы ⓘ немесе «Тіркелу» басқанда «Тіркелмес бұрын» терезесі (танысып шықтым → тіркелу).
- Кестедегі чемпион: алтын карточка — тәж, алтын жиекті аватар, аты, «ЧЕМПИОН», белбеу.
- Кесте (уақыт сызығы) әр кезеңнің нақты күні мен уақытын көрсетеді.

## Атауы және форма (2026-10-06)
- Сервис атауы: **«Турниры»** (staff және студент), иконка `cup_line.png`. Плиткада белсенді кубок саны.
- Форма қадамдары қайта бөлінді (әр қадамда ақпарат біркелкі):
  1. **Негізгі** — Атауы, Пән, Формат (3 плитка: Олимпиялық / Швейцар / Арена + сипаттама бір жолда), формат параметрлері (кезең саны ↔ қатысушылар).
  2. **Қатысушылар** — кімге ашылады (бас куратор), топтар, жұптастыру, check-in, **Жүлде**: чемпионға 100 / 200 / 500 I4U монета; 2-орын — жартысы, 3-орын — ширегі; чемпионға + белбеу.
  3. **Мазмұн** — пән жолағы (1-қадамнан), модульдер, тақырыптар, баннерлер (3-ке дейін).
  4. **Уақыт** — бұрынғыдай + алдын ала қарау.
- Деректер: `Tournament.prize` (чемпион монетасы).

- Студент басты бетінде реті: … Аналитика · **Магазин** · Батл · **Турниры** (2026-10-06).

## Карточка және форма мінез-құлқы (2026-10-06)
- Турнир карточкасы: куратор баннер жүктесе — белбеу иконкасының **орнына** бірінші баннер карточканың жоғарғы жағында толық ені бойынша шығады (биіктігі 112, радиус 12, `cover`). Баннер жоқ болса — бұрынғыдай белбеу иконкасы 60×60. Тоқтатылған турнирде баннер сұр.
- Форма: қадам ауысқанда және кез келген батырманы басқанда парақша **анимациясыз** орнында жаңарады (қайта жоғарыдан шықпайды, қимылдамайды). Бір қадам ішінде айналдыру орны сақталады; қадам ауысқанда — басына. Flutter: `AnimatedSwitcher` қолданбаңыз, `setState` жеткілікті; парақша `showModalBottomSheet` бір рет ашылады.

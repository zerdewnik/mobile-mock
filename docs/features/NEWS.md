# Жаңалықтар, тексеру және баннер — техникалық сипаттама

Макет: `#staff` → Новости. Рөлді ауыстыру (макетте): телефонның үстіндегі «Рөл: Куратор / Бас куратор / Академ. бөлім».
Код: `renderStaffNews()`, `openNewsForm()`, `openNewsReview()`, `openMyNews()`, `bannerHtml()`.

## Рөлдер
| Рөл | Құқығы |
|---|---|
| Куратор | Жаңалық жазады → **тексеруге** кетеді; өз жаңалықтарының мәртебесін көреді; қайтарылғанын түзетіп қайта жібереді |
| Бас куратор / Академиялық бөлім басшысы (барлық топты көреді) | «Тексеру» қойындысы: жариялайды немесе себебін жазып қайтарады; өзі жазғаны бірден жарияланады |
| Студент | Тек жарияланған жаңалықтарды көреді; баннерлер басты бетте |

## Жаңалық өрістері
| Өріс | Ереже |
|---|---|
| Тақырып * | 1–80 таңба |
| Мәтін * | бос емес |
| Сурет | JPEG/PNG, сервер 900px-ке дейін кішірейтеді |
| Баннер ретінде көрсету | қосулы болса, жарияланғанда студенттің (және staff) басты бетіндегі баннер каруселіне шығады; суреті болмаса — бренд градиенті |
| Кімге | Барлық студенттер / Автордың топтары |

## Мәртебелер
`pending` (Тексеруде, сары) → `published` (Жарияланды, жасыл) немесе `rejected` (Қайтарылды, қызыл + себебі).
Қайтарылған → автор түзетеді → қайтадан `pending`.

## Баннер
- Карусель: алдымен баннер-жаңалықтар (жаңасы бірінші), соңында тұрақты I4U баннері. Солға-оңға сырғиды, нүктелер — бет нөмірі.
- Өлшемі: ені экран − 24, пропорция 2.55:1, radius 15. Мәтін: тақырып 16/w800, сипаттама 11 (70 таңбаға дейін).
- Баннерді басқанда — жаңалықтың толық беті.

## Хабарламалар (пуш)
- Тексерушілерге: «Жаңа жаңалық тексеруді күтуде: {тақырып}».
- Авторға: «Жаңалығыңыз жарияланды» / «Жаңалығыңыз қайтарылды: {себеп}».
- Студенттерге (жарияланғанда, міндетті емес): «{тақырып}».

## API (ұсыныс)
```json
News { "id": 90, "title": "...", "body": "...", "imageUrl": null, "isBanner": true,
       "audience": "all | groups", "groupIds": [], "authorId": 5,
       "status": "pending | published | rejected", "rejectReason": null,
       "createdAt": "...", "reviewedBy": null, "reviewedAt": null }
```
`POST /news` · `PUT /news/{id}` · `GET /news?status=published` · `GET /news?status=pending` (тексерушілер) · `POST /news/{id}/approve` · `POST /news/{id}/reject {reason}` · `GET /banners` (жарияланған `isBanner` + тұрақты).

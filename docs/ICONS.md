## 2. Өз файлдарымыз

Flutter-ге қосу: файлдарды `assets/` папкасына көшіріп, `pubspec.yaml` ішіне жазыңыз:

```yaml
flutter:
  assets:
    - assets/v2/
    - assets/logo/
    - assets/tournament/
    - assets/champion/
  fonts:
    - family: Roboto
      fonts:
        - asset: assets/fonts/Roboto-Regular.ttf
        - asset: assets/fonts/Roboto-Medium.ttf
          weight: 500
        - asset: assets/fonts/Roboto-Bold.ttf
          weight: 700
```

SVG үшін `flutter_svg` пакеті: `SvgPicture.asset('assets/tournament/trophy.svg', width: 96)`.

### 3D турнир иконкалары туралы
`assets/tournament/*.svg` — градиент + жарқыл + түскен көлеңке (feDropShadow) арқылы 3D әсер. Түстері: алтын `#FFF1B8 → #FFD24D → #E0A21B → #9A6608`, көк `#8A94F5 → #5B6EC2 → #3B4089`.
`flutter_svg` кейбір версияларында `filter` (көлеңке) қолдамайды — онда виджетке `BoxShadow`/`PhysicalModel` қосыңыз немесе PNG экспорттаңыз (`@2x`, `@3x`).

# Компоненттер

Әр компонент: **не үшін**, **өлшемі**, **түсі**, **күйлері**, макеттегі CSS класы және Flutter-дегі ұсыныс.
Түс атаулары `design-tokens.json` / `flutter/i4u_theme.dart` ішіндегі `I4UColors`.

> Тірі мысал: https://zerdewnik.github.io/mobile-mock/ (студент) және `#staff` (куратор).
> Макетте элементті тінтуірдің оң жағымен → «Inspect» басып, нақты пиксель мен түсті көруге болады.
